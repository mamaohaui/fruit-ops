# HTML 简约数据展示页面生成规范

## 核心原则

生成的所有 HTML 页面必须同时满足两个要求：

1. **极简设计**：去除一切装饰性元素，只保留必要的视觉层级。少即是多。
2. **数据清晰**：数据是页面的主角，任何设计决策都必须服务于数据的可读性和可对比性。

---

## 设计令牌（Design Tokens）

### 色彩系统
```
背景色：     #ffffff（卡片）/ #f8f9fa（页面底色）
主文字：     #1a1a2e（标题）/ #333（正文）
辅助文字：   #6b7280（次要信息）
边框：       #e5e7eb（分割线/卡片边框）
主色强调：   #2563eb（链接/选中/关键指标）
成功/增长：  #059669（正向数据）
危险/下降：  #dc2626（负向数据）
图表色板：   ["#2563eb","#7c3aed","#059669","#d97706","#dc2626","#0891b2","#4f46e5","#be185d"]
```

### 排版
```
字体：       system-ui, -apple-system, 'Segoe UI', sans-serif
标题字号：   28/24/20/18/16px（H1→H5）
正文字号：   14px（表格/列表）/ 13px（辅助信息）
数字字号：   24-32px（关键指标数值，font-weight: 700，font-feature-settings: "tnum"）
字重层级：   400（正文）/ 500（强调）/ 600（小标题）/ 700（大标题/数字）
行高：       1.5（正文）/ 1.3（标题）/ 1（数字）
```

### 间距系统（4px 基准）
```
xs: 4px  |  sm: 8px  |  md: 16px  |  lg: 24px  |  xl: 32px  |  2xl: 48px
```

### 圆角
```
卡片：8px  |  按钮：6px  |  输入框：6px  |  标签/徽标：4px  |  头像：50%
```

### 阴影（仅使用两级）
```
卡片：0 1px 3px rgba(0,0,0,0.06), 0 1px 2px rgba(0,0,0,0.04)
悬浮：0 4px 6px rgba(0,0,0,0.05), 0 2px 4px rgba(0,0,0,0.04)
```
> 不要使用过重的阴影，保持页面轻盈。

## 核心组件规范

### 统计指标卡片（Stat Card）
```
结构：label（上，小字灰色）→ value（中，大字加粗）→ change（下，带箭头和颜色）
要求：
- 卡片背景纯白，细边框
- 数值使用 tabular-nums（等宽数字）确保对齐
- 增长用绿色 + ↑，下降用红色 + ↓
- 可选：迷你趋势图（纯 CSS 或 SVG 占位）
```

### 数据表格（Data Table）
```
要求：
- 表头灰色背景（#f9fafb），文字加粗
- 斑马纹（奇数行白色，偶数行 #f8fafc）
- 行 hover 时浅蓝背景（#f0f7ff）
- 分割线使用 #e5e7eb，不要使用竖向分割线
- 数字列右对齐，文字列左对齐
- 操作列固定在右侧
- 支持按列排序的三角箭头提示
```

### 图表占位区域（Chart Placeholder）
```
当不需要真实图表库时，使用以下方案：
- 纯 CSS 柱状图：flexbox + 不同高度的 div
- SVG 折线图占位：简单的 path + 渐变填充
- 环形进度：SVG circle + stroke-dasharray
- 都标注"chart-placeholder"类名，方便后续替换
```

### 筛选工具栏（Filter Bar）
```
一行水平排列：搜索框（左侧，宽度 240-320px）+ 下拉筛选器 + 日期选择器 + 操作按钮
所有控件高度统一 36-40px
间距 12px
```

## 内容组织原则

1. **信息层级扁平化**：最多三层信息（标题 → 摘要 → 细节），不要嵌套太深
2. **留白即分隔**：优先用留白而非分割线区分内容区块
3. **对齐严格**：同类数据必须同一垂直线上对齐
4. **数字突出**：数据比标签更重要，数值字号应大于标签字号
5. **操作收敛**：每行最多 3 个操作按钮，更多操作收入"···"下拉菜单
6. **空状态友好**：无数据时显示居中的空状态占位（图标 + 引导文字 + 操作按钮）

---

## 禁止使用的元素

- ❌ 渐变背景（允许用于图表数据系列色）
- ❌ 大阴影 / 多层阴影
- ❌ 装饰性图标（仅保留功能性图标）
- ❌ 动画（除 hover 过渡和骨架屏加载外）
- ❌ 彩色边框（边框统一用 #e5e7eb）
- ❌ 超过 3 种字体大小在同一区域
- ❌ emoji 作为主要图标（可以用在空状态占位中）

## 模板：仪表盘页面提示词

```prompt
创建一个数据仪表盘 HTML 页面。

## 设计风格
极简主义，白色背景，低对比度分割线，数据为视觉焦点。

## 必须包含
### 1. 顶部导航栏
- 左侧：Logo/产品名
- 右侧：搜索框（简洁，240px宽）+ 用户头像（圆形占位）

### 2. 统计卡片行（4 张）
- 每张卡片：指标名称（12px 灰色）→ 数值（28px 加粗）→ 变化率（绿色↑/红色↓ + 百分比）
- 卡片背景白色，细边框，8px 圆角，hover 轻微上浮
- 数值使用等宽数字字体（font-feature-settings: "tnum"）

### 3. 图表+列表双栏区域
- 左侧（2/3 宽）：纯 CSS 柱状图（12 个月数据），柱体使用主色，hover 变色
- 右侧（1/3 宽）：最新记录列表（5 条），带状态标签和时间

### 4. 数据表格（全宽）
- 8 列示例数据（ID/名称/类别/数量/金额/状态/日期/操作）
- 斑马纹行，固定表头，hover 高亮行
- 状态列使用彩色标签（成功/待处理/失败）
- 表格上方有筛选工具栏

## 技术实现
- 纯 HTML + CSS + Vanilla JS，单文件
- 使用 CSS 变量管理颜色和间距
- 不使用任何外部依赖
- 完全响应式（移动端卡片堆叠，表格横向滚动）
```

## 模板：数据详情页提示词

```prompt
创建一个数据详情展示页面。

## 设计风格
极简，白色卡片，数据以清晰的标签-数值对形式展示。

## 必须包含
### 1. 顶部导航
- 返回按钮 + 标题 + 状态标签（彩色圆点+文字）

### 2. 两栏布局
- 左侧（2/3）：核心信息卡片
  - 使用描述列表（Description List）布局：标签灰色左对齐，数值深色右对齐
  - 分组展示，组间留白分隔
- 右侧（1/3）：辅助指标
  - 关键数字突出显示
  - 时间线/操作日志

### 3. Tab 切换区域
- 关联数据标签页（如：订单明细/操作日志/附件）
- 每个 Tab 包含对应的表格或列表

## 技术实现
- 纯 HTML + CSS + Vanilla JS，单文件
- CSS Grid 两栏布局
- 响应式：移动端两栏变为上下堆叠
```
