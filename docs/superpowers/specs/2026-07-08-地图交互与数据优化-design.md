## 一、省份点击平滑 Zoom

### 现状

点击省份多边形 → 切换加载该省 GeoJSON 子地图（省级/市级地图），散点重新渲染在子地图上。

### 目标

始终停留在中国地图，点击省份时 ECharts 平滑动画 zoom 到该省份区域。

### 实现方案

**移除子地图**：不再加载省级/市级 GeoJSON。删除 `renderMap()` 中的 province/city 级别分支，始终使用 `'china'` map。

**点击省份多边形**：计算该省所有产区散点的 bounding box → 用 `mapChart.dispatchAction` 做平滑 center/zoom 过渡：

```javascript
// 伪代码
var lat = (bbox.minLat + bbox.maxLat) / 2;
var lng = (bbox.minLng + bbox.maxLng) / 2;
var span = Math.max(bbox.maxLng - bbox.minLng, bbox.maxLat - bbox.minLat, 0.5);
var zoom = Math.min(600 / span, 20);
mapChart.setOption({ geo: { center: [lng, lat], zoom: zoom } }, { notMerge: false });
```

**点击散点进一步 zoom**：在省份 zoom 视图中点击散点 → 进一步 zoom 到该市所有产区 bbox。市级是最大缩放层级。

**"回到全国"按钮**：右上角新增返回按钮，仅在非默认视图时显示，点击恢复 `center: [105, 36], zoom: 1.2`。

**侧边栏详情面板**：保持现有逻辑，点击省份显示省份详情，点击散点显示产区详情。

### 涉及改动

| 文件 | 改动 |
|---|---|
| `中国水果产区数据大屏.html` | `renderMap()` 重写，移除子地图加载；click handler 改为 center/zoom 计算；新增"回到全国"按钮；删除 `geoMapCache`、`provAdcodeMap` 等子地图相关变量 |
| `server.py` | 无改动（地图数据不做变化） |

## 二、高德 API 自动获取坐标

### 现状

新增产区时如果客户端不传 `lng`/`lat`，坐标默认存为 `0`。无地理编码能力。

### 目标

后端在创建/更新产区时，自动调用高德 API 查询省+市+县+镇对应坐标。

### 实现方案

**高德 API 配置**：
- Web 服务 Key：`d60264473fe914fa0cf21d1a22a4e206`
- 安全密钥（数字签名）：`ae7d546c1e8f25d8365b2c601fd3c96a`
- 使用 `/v3/geocode/geo` 接口（地理编码）

**后端新增模块**（`server.py` 内）：

```python
import hashlib
import urllib.request
import json

AMAP_KEY = "d60264473fe914fa0cf21d1a22a4e206"
AMAP_SECRET = "ae7d546c1e8f25d8365b2c601fd3c96a"

def geocode(province, city="", district="", town=""):
    """调用高德地理编码 API，返回 (lng, lat) 或 (0, 0)"""
    address = "".join([province or "", city or "", district or "", town or ""])
    if not address.strip():
        return 0, 0
    # 高德 API 签名规则：MD5(/v3/geocode/geo?parameters&key=xxx + secret)
    params = f"address={urllib.parse.quote(address)}&output=JSON"
    sig_raw = f"/v3/geocode/geo?{params}&key={AMAP_KEY}{AMAP_SECRET}"
    sig = hashlib.md5(sig_raw.encode()).hexdigest()
    url = f"https://restapi.amap.com/v3/geocode/geo?{params}&key={AMAP_KEY}&sig={sig}"
    try:
        resp = json.loads(urllib.request.urlopen(url, timeout=5).read())
        if resp.get("status") == "1" and resp.get("geocodes"):
            loc = resp["geocodes"][0]["location"]  # "116.397,39.908"
            lng, lat = loc.split(",")
            return float(lng), float(lat)
    except Exception as e:
        print(f"[geocode] 查询失败: {address}, 错误: {e}")
    return 0, 0
```

**调用时机**：

| 端点 | 时机 | 行为 |
|---|---|---|
| `POST /api/fruits` | 创建水果后自动创建产区行 | 若 lng/lat 为 0，调用 `geocode()` 补全 |
| `PUT /api/fruits` | 修改水果产地信息 → 同步更新产区 | 若产区坐标仍为 0，调用 `geocode()` 补全 |
| `POST /api/sync-all` | 前端批量同步 | 遍历 regions，对 lng=0 的行调用 `geocode()` 补全 |

**失败处理**：查询失败不阻塞操作，坐标保持 0，打印警告日志。

### 涉及改动

| 文件 | 改动 |
|---|---|
| `server.py` | 新增 `AMAP_KEY`/`AMAP_SECRET` 配置、`geocode()` 函数；在 `create_fruit()`、`update_fruit()`、`sync_all()` 中集成 |
| `启动.bat` | 无改动（不需要额外依赖，用标准库 urllib + hashlib） |

## 三、生长期 & 暂无数据合并

### 现状

5 种状态：盛产期(红)、尾产期(紫)、成熟期(橙)、生长期(绿实心)、暂无数据(灰虚线空心)

### 目标

合并生长期和暂无数据，统一为绿色空心圆。规则：不在成熟期/盛产期/尾产期的，全都归类为生长期。

### 实现方案

**`fruitPhase()` 修改**：原返回 `-1`（暂无数据）改为返回 `0`（生长期）。实际上就是删除返回 `-1` 的分支。

**`buildScatterPoint()` 修改**：phase 0 的样式改为：
- `color`: `'transparent'`（透明填充，空心效果）
- `borderColor`: `'#52c41a'`（绿色边框）
- `borderWidth`: `2`
- `borderType`: `'solid'`（实线边框）
- `symbolSize`: `6`（统一小尺寸）

**图例更新**（HTML 底部 `.map-legend`）：4 项 → 盛产期(红)、尾产期(紫)、成熟期(橙)、生长期(绿空心)

**`regionPhase()` 保持不变**：优先级逻辑不变，只是 phase 只有 4 种值（2/3/1/0），不再有 `-1`。

**`phaseColors` / `phaseBorderColors` 映射更新**：删除 key `-1`，key `0` 改为透明/绿色边框。

### 涉及改动

| 文件 | 改动 |
|---|---|
| `中国水果产区数据大屏.html` | `fruitPhase()` 删除 `-1` 分支；`buildScatterPoint()` 修改 phase 0 样式；更新 `phaseColors`/`phaseBorderColors`/图例 HTML |
